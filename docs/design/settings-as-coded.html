Light · surface #FFF, groups #F4F4F4
  • App bar — 64px toolbar, "Settings" at 22px w800, ls −0.4 (AppBarTheme.titleTextStyle). The earlier reference panel showed it regular-weight — fixed here.
  • Groups — one surface per group: dark #151515 / light #F4F4F4, radius 16, 28px between groups (sectionGap). Label 12 w700 ls 0.2 in onSurfaceVariant.
  • Rows — 13px vertical padding, 34px tile (#242424 / #E6E6E6, radius 10, 19px glyph), title 15 w600, subtitle 12 in onSurfaceVariant (#B3B3B3 / #4A4A4A).
  • Trailing — chevron_right_rounded 20px in outline (#7A7A7A / #6B6B6B); state rows add the On/Off pill with an 8px gap before the chevron.
  • Dividers — 1px outlineVariant (#333333 / #DEDEDE), indented 62px to start at the title, 16px short on the right.
  • Strings — About subtitle is AppInfo.versionLabel: "Version 1.3.4 (build 9)" (the old panel showed "v1.4.0"); footer is AppInfo.tagline. Reminders subtitle switches live: "Checking status…" → "Alerts before each class" / "No alerts scheduled".
