# Klasify full-app audit — 2026-10-31

OCR work (v1.4.0+10). Supersedes the 2026-10-20 snapshot in
`FULL_APP_AUDIT.md` (kept for reference). Method note: this audit was
produced in a sandbox **without the Flutter SDK**, so `flutter analyze`,
`flutter test`, and device builds could not be run here; everything below
is either source-verified, measured through the pure-Dart benchmark
harness (`tool/cor_harness/`, Dart 3.5.4), or explicitly listed as
outstanding device verification.

## 2. Feature inventory (source-verified)

- **Schedule**: weekly grid, day chips, class CRUD with undo, per-class
  status marks (done/skipping/cancelled) with unmark-restore semantics
  (reminder rework, reminder planner isolated in
  `lib/services/reminder_service.dart`, 17-scenario test file).
- **Import**: images/screenshots + PDF (first 8 pages, rendered locally),
  on-device PaddleOCR with bundled models, draft review screen with
  warnings, conflict checks, single-transaction save. COR-specific parser
  (`CorScheduleParser`) with day-first slot canonicalization, compound
  meeting-day expansion, room vocabulary, trailing-room reassignment.
- **Reminders**: exact alarms, boot re-scheduling, per-class prep-time
  offsets, permission recovery UI.
- **Home-screen widget**: next-class widget (Android AppWidgetProvider,
  calendar-style layout), refreshed from the schedule service.
- **Backup**: JSON export/import screen, atomic restore.
- **Onboarding**: 3-page first-run tour + replayable coach tour.
- **Crash reporting (opt-in)**: Sentry via
  `--dart-define=KLASIFY_SENTRY_DSN`; dormant without it
  (`lib/services/crash_reporting.dart` + test). Offline reports queue and
  upload later; never includes schedule content.
- **Theming**: light/dark, component kit (`widgets/component_kit.dart`),
  swipe actions, coach hints.

## 3. OCR pipeline state (measured through the benchmark harness)

(softness gate) → Adaptive threshold → Lighting flattened → **Dewarp
rescue (new, round 12)** → Dark-background inversion → High-res crisp
rescue → Deskew brackets → (rotation fallback). Stop gate: conf >= 0.85

## 4. Known OCR limitations (current, ordered)

1. **Shadow-band room cells — 8/10.** Two room cells sit fully inside the
   darkest cast-shadow band; the flatten rescue recovers the rows but not
   those two cells. Open.
2. **Grid-layout photos — harness-boundary.** Whiteboard/angled-grid
   fixtures route through the grid scanner stage that the VM harness
   cannot run; needs the device-side audit (`bench5`/`bench6` cover that
   stage on device). Open.
3. **Chat coreference — 2 misses.** "Wed same time same room" needs
   row-carried context across bubbles (`r11_chat_multi.png` 3/5). Open.
4. **Free-text dotted PM times + compound-day intercept — 1 miss.**
   `Ethics Wed 2.00-3.30 PM Rm 9` style lines and three probe formats
   (compound day tokens, day ranges, slash day pairs) mis-route through
   the sectioned parser. Open.
5. **Warped-page auxiliary fields — closed this round** (room 6/10,
   prof 9/10; on-device confirmation outstanding).
6. **Standing caveats (by design):** OCR confidence is a signal, not
   proof; every import is reviewed before saving; rooms that are not
   recognized are flagged "Room to confirm"; nothing is uploaded.
